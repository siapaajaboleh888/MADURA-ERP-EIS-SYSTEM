- **Mata Kuliah**: Manajemen Proyek Perangkat Lunak (OBE 2026)
- **Capaian (Evaluasi CPMK 2 - Bobot 25%)**: Studi Lapangan, Audit Dokumen Testing Fase 1, Peer Review Hasil Uji Black-Box dan White-Box.

1. **Audit Keterlacakan (Traceability Audit)**:

2. **Audit Defect Log**:
   - Defect log `docs/defect-log.md` terstruktur rapi memuat ID, Severity, Priority, Status, dan Root Cause untuk 5 skenario defect simulasi lab.
3. **Hasil Evaluasi**: **LULUS (AUDIT COMPLIANT)** — Seluruh artefak Pekan 1 s/d 7 valid dan terverifikasi.
