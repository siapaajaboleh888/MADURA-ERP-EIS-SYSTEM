# Laporan Pengujian Pekan 11: User Acceptance Testing (UAT) & Sign-Off Governance

## 1. Identitas Mata Kuliah & Modul RPS
- **Mata Kuliah**: Manajemen Proyek Perangkat Lunak (OBE 2026)
- **Sub-CPMK 10**: Mampu merancang skenario User Acceptance Testing (UAT), matriks kriteria penerimaan, dan Berita Acara UAT (Sign-off Document) bersama stakeholder UMKM.
- **Artefak Sasaran**: Dokumen UAT Governance (`docs/uat/`)

## 2. Kriteria Penerimaan Pengguna (Acceptance Criteria)
1. **Penerimaan Modul Penjualan**: Pengelola UMKM garam dapat membuat pesanan penjualan dan melihat kalkulasi invoice otomatis tanpa eror hitung.
2. **Penerimaan Modul Gudang**: Petugas gudang dapat melihat saldo stok real-time garam per lokasi gudang (Gudang Pamekasan / Sumenep).
3. **Penerimaan Modul EIS**: Pimpinan / Direksi dapat melihat grafik total pendapatan terselesaikan (*settled revenue*) dan tagihan tertunda (*outstanding invoices*).

## 3. Berita Acara UAT
- Seluruh 15 skenario pengujian bisnis diterima oleh pengguna perwakilan. Status: **PASS (ACCEPTED FOR DEPLOYMENT)**.
